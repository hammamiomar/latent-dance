# Attribution And License Matrix

## What latent-dance Provides

latent-dance provides the audio-reactive steering runtime, FastAPI/WebSocket server, React/Electrobun interface, perceptual audio bridge, feature-label integration, and public label/activation dataset tooling.

## What latent-dance Does Not Claim

The SDXL-Turbo sparse autoencoders/checkpoints were not trained by latent-dance. They were trained and released by Surkov et al. / EPFL through the `sdxl-unbox` project.

Use this wording in public docs and dataset cards:

> latent-dance uses SDXL-Turbo sparse autoencoders trained and released by Surkov et al. / EPFL through `sdxl-unbox`. This project contributes audio-reactive steering, runtime integration, and a public dataset of labels/activations for those upstream SAE features.
